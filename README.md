### About

<img align="right" width="320" src="https://i.postimg.cc/NFtbXhP7/giphy.gif" alt="coding" />

CTO at **[VirexTech](https://github.com/Virex-Tech)**, a small studio in Brazil. We build our own apps and we run them.

- 🧪 Backend and infra, plus whatever the app needs that week
- 📱 Health, fitness and finance apps, live on both stores
- 🤖 Most of my work goes through AI agents now, behind a review gate that says no
- 🎯 A feature isn't done until it's in production and I can measure it
- 💬 TypeScript, Fastify, Next.js, React Native, Postgres
